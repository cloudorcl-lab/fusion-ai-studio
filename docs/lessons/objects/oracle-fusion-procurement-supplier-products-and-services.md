# Supplier Products and Services

- Product/release: Oracle Fusion Cloud Procurement 26C; API `11.13.18.05`.
- Collection: `/suppliers/{SupplierId}/child/productsAndServices`; item key: `SupplierProductsServicesId`.
- Documented operations: GET, POST, DELETE. Source: [26C endpoint index](https://docs.oracle.com/en/cloud/saas/procurement/26c/fapra/rest-endpoints.html).
- Current BO functions: `ListSupplierProductsAndServices` and `CreateSupplierProductsAndServices`; category lookup uses `XDX_SUPPLIER_PRODUCT_SERVICE_CATEGORIES.ListSupplierProductServiceCategories`.

## POST

Resolve an existing target-tenant category for the selected supplier. Submit `ProductsServicesCategoryId` and `CategoryType`; omit generated association ID, name, description and audit fields. The browsing-categories lookup returns hierarchy/catalog `CategoryType=SUPPLIER`, while this association requires `CategoryType=BROWSING` for that selected category. The target tenant rejected `SUPPLIER` with `POZ-2130498`; read-only reconciliation confirmed no record before the corrected POST. The corrected create returned `SupplierProductsServicesId=300000333814294` for Computer Supplies (`300000047322441`), and the independent GET matched both IDs and `CategoryType=BROWSING`.
