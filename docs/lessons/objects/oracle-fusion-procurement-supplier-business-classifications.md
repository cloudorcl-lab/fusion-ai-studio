# Supplier Business Classifications

- Product/release: Oracle Fusion Cloud Procurement 26C; API `11.13.18.05`.
- Collection: `/suppliers/{SupplierId}/child/businessClassifications`; item key: `ClassificationId`.
- Documented operations: GET, POST, PATCH, DELETE. Source: [26C operation page](https://docs.oracle.com/en/cloud/saas/procurement/26c/fapra/api-suppliers-business-classifications.html).
- Current BO functions: `ListSupplierBusinessClassifications` and `CreateSupplierBusinessClassification`.

## POST

For the required-field-only create, submit `ClassificationCode`; omit generated `ClassificationId`, status, certificate, contact, audit, DFF and attachment fields. The target-tenant live create used `SMALL_BUSINESS`, returned `ClassificationId=300000333814290`, and an independent parent-scoped GET returned the same ID and code with `Status=CURRENT`.

First successful BO GET sample (2026-09-23, supplier `300000333814250`): `{"items":[{"ClassificationId":300000333814290,"ClassificationCode":"SMALL_BUSINESS","Classification":"Small Business","Status":"CURRENT"}],"count":1,"hasMore":false}`.
