# Dependency and Evidence Inventory

| Dependency | Owner / consumer | Decision | Verification |
| --- | --- | --- | --- |
| Startup package and seed | Packet producer / future builds | Retain delivery snapshot | Manifest and startup verifier |
| Root instructions and playbook | Repository / future sessions | Activate one lifecycle owner | Contract and regression |
| Skill, CLI and references | Packet producer / authoring | Activate matching version | Seed hashes, syntax and help |
| Records and audit | Installation agent / rollback | Retain | Receipt and path inventory |
| External backups | User / recovery | Retain until explicitly retired | Before-hash parity |
| Git, PowerShell, Node | Local host / verifiers | Retain existing tools | Command results |
| Environment and apps | Existing project / runtime | Preserve | Baseline hashes |

No live, replay, DRAFT or PUBLISHED evidence. Recovery copies are not active lifecycle owners.
