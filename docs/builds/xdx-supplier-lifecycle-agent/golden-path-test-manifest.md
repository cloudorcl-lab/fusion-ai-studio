G01 includes correction, cancellation, stale approval and new-draft state isolation. G02 includes exact/partial/number selection, ambiguous result, pagination, empty/error distinction and child-parent scope. G03 includes source choice, apply-all, override and absent-reference collection, limited to required fields. G04-G07 include rejection/revision, generated-ID omission, valid foreign references and full intended-field readback, using fixtures except the explicitly approved live baseline. G08 expands into G08A through G08I; excluded resources have no route. G09 covers unknown POST outcome, partial child completion, repeated approval and reconciliation; it must not repeat confirmed creates.

Cumulative phase N includes enabled G01 through GN (G00 is governance evidence), with one canonical configured-mode suite per changed phase after discrete tests and sync completion. Exact executable test paths come from ATLAS, never fabricated in planning.

P2 ATLAS disposition: the focused plan reached `finalSummaryAllowed: true` with no create/update action. Eight predicted branch combinations were deferred after two valid-route observations because they combine mutually exclusive upstream states. The executable supported routes are retained in `direct-address-resolved-child-execution`, `direct-site-resolved-child-execution` and `direct-contact-resolved-child-execution`; each runs its parent lookup and selected child BO. The deferred predicted combinations are not described as executed.
